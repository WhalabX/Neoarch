# Keyboard Shortcuts

Speed up your workflow with these shortcuts. Shortcuts work in every view of the
main window unless a text field has focus.

## Global

| Shortcut | Action |
|----------|--------|
| `Ctrl+F` | Focus the search bar |
| `Ctrl+R` | Refresh the package list |
| `Ctrl+I` | Install the selected package(s) |
| `Ctrl+U` | Update the selected package(s) |
| `Ctrl+D` | Remove the selected package(s) |
| `F1` | Show help |
| `F5` | Refresh the current view |
| `Esc` | Clear the search / close the current dialog |

## Notes

- `Ctrl+R` and `F5` both re-query the active package source; the AUR source is
  re-searched live, so results appear as you type.
- Removal shortcuts ask for confirmation, and a running transaction is never
  interrupted silently — progress is shown in the log panel.
- The in-app help dialog (**Help → Keyboard Shortcuts**) lists the same table
  for the installed version.
